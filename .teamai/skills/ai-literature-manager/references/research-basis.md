# 设计依据与回归场景

依据：用户项目在 2026-10-23 形成的《项目调研.md》《调研样本/六篇论文试读与插件需求.md》及 `pilot-reading-v0.1` 结构化试读。原报告仍在用户项目中；此处保存可独立携带的需求摘要，不依赖它们在其他机器上存在。平台与竞品资料未作为本技能已实现能力，也未在创建本技能时重新联网验证。

| 调研结论 | 技能落地 |
|---|---|
| 一篇一行总表与单篇纵向拆解共用数据 | SQLite 记录，CSV 总表，Markdown 总表及详情，JSON 完整快照 |
| 经管 × 计算机，但六篇样本以财报基准为主 | 通用字段 + 基准/经管/计算机扩展；基准口径优先 |
| 两篇 CFQA 缩写相同、身份不同 | 文件哈希去重，paper_id 区分；题名/DOI 只提示候选 |
| 总库、公开样本和实际评测子集易混淆 | 独立 evaluation_sample，实验记录绑定 subset/n/setting |
| 原文数字及表格存在冲突 | conflicting 状态、issues 列表，保留原值，不自动修正 |
| 论文证据与底层年报证据有两层 | PDF 引文 evidence 与 benchmark_evidence 字段分开 |
| AI 抽取不是用户已读，文字匹配不是语义核验 | coverage / reading_status / review 分离 |
| 中英文与人工修改需要长期保留 | 双语值、独立用户层、历史修订与事务 |

## 真实材料回归检查

已有样本用于设计和回归，不是独立验收金标准。重点检查：

- Gan-CFQA 与 Zhu-CFQA 导入后仍为两条；相同字节重复导入不增记录。
- FinanceBench 全库与 150 题评测范围保持区分，不能把 10,231 当作实测分母。
- ARQA 2,448 与分项合计 2,450 的疑点保留；35 位专家的审核范围不扩成所有题型。
- FinRank 的 Recall@10 不改写为答案准确率；FinDVer testmini/test 与人类抽样分母分开。
- 用户改一个字段后 AI 重跑，有效值和用户笔记不被覆盖，旧版在 history 中可查。
- 原文页码越界、缺证据的作者事实、过期 revision 的批次写入被拒绝，库里其他字段不产生半更新。

这些是记录与操作流程的检查；不证明抽取语义正确率。后续语义验收另选未用于设计的中英文全文及混合版面论文。
